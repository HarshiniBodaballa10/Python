# 🐍 Python Mini Projects Collection
A collection of beginner to intermediate Python projects developed to strengthen programming fundamentals, problem-solving skills, GUI development, automation, and AI concepts.
This repository demonstrates practical applications of Python through multiple standalone projects covering core programming, user interaction, GUI applications, and voice automation.
---

## 📌 Projects Included
| Project | Description | Technologies |
|---------|-------------|--------------|
| 🧮 Calculator | Performs basic arithmetic operations including addition, subtraction, multiplication, division, and modulus. | Python |
| ⏰ Alarm Clock | GUI-based alarm clock with custom time selection and alarm notification. | Tkinter, Threading |
| ⏳ Countdown Timer | Displays a live countdown timer in HH:MM:SS format. | Time Module |
| ✂️ Rock Paper Scissors | Play against the computer using randomly generated choices. | Random Module |
| 📝 To-Do List | Console-based task management application to add, remove, and display tasks. | Lists, Functions |
| 🌡️ Temperature Converter | Converts temperatures between Celsius and Fahrenheit. | Python |
| ⚖️ Weight Converter | Converts weight between kilograms and pounds. | Python |
| 📧 Email Slicer | Extracts username and domain from an email address. | String Manipulation |
| 🎭 Mad Libs Game | Interactive word game that generates fun stories from user input. | Strings |
| ❓ Quiz Game | Multiple-choice quiz with score calculation. | Lists, Loops |
| 🤖 HARSHI Voice Assistant | Voice-controlled AI assistant capable of answering queries and performing system tasks. | Speech Recognition, Text-to-Speech |

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/HarshiniBodaballa10/Python.git
```

Move into the project directory

```bash
cd Python
```

Install required libraries

```bash
pip install speechrecognition pyttsx3 pywhatkit wikipedia pyjokes pyaudio
```

# ▶️ Running Projects

Run any project using Python.

Example:

```bash
python calculator.py
```

```bash
python Alarm.py
```

```bash
python assistant.py
```

